Comparison
  Baseline: 30 query frames + recognition instruction.
  With examples: three labelled 30-frame demonstrations with approved text,
                then the same 30 query frames + the same recognition instruction.
This proposed configuration totals 120 images in the example condition.
Check image handling, context capacity, truncation and runtime on development
before approving the configuration. Any reduction in example image counts
must be declared and frozen separately, with exact positions and hashes.

according to the query's true label. Send neutral image positions, not class
folder names, source annotations, references or match paths for the query.
Keep model tag/digest, settings, query sampling and instructions identical.
Use separate fresh requests: no previous answers or human corrections.
